# Not Gate Using Verilog HDL
# overview
- This projects implements and verifies a Not Gate using Verilog HDL in xilinx vivado.

# objectives
- Design a NOT Gate using Verilog HDL.
- understand the NOT Gate Boolean expression and truth table.
- Develop a testbench to verify its functionality.
- perform behavioral simulation using Xilinx vivado.

# Boolean expression
- Y = ~A
- Where A is input and Y is output

# conclusion
- The NOT Gate is successfully designed and simulated using Verilog HDL. The simulation results confirmed that the output is always the complement of the input.
- This projects demonstrates the fundamental of combinational logics design and functional verification using Xilinx Vivado.
